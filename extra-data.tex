\subsection{Evaluation on additional datasets}
We first test whether the benefit of diversity-aware base selection extends
beyond CIFAR-10. CIFAR-100 provides a more constrained setting with many more
classes and only 500 training candidates per adversarial class, and therefore
uses ResNet18BN. SVHN provides a complementary shift from natural images to
street-view digits while retaining the 32\(\times\)32 resolution and the
ConvNetBN backbone. Table~\ref{tab:cross-dataset} reports the original
five-instance comparison. DPP improves ASR for both GM and SAPA on all three
datasets. Absolute ASR values should not be compared across dataset rows because
the number of classes, candidate-pool size, and backbone differ.

The preceding comparison holds the attack and budget fixed, so we additionally
evaluate a broader, deliberately non-exhaustive grid in
Table~\ref{tab:cross-dataset-selection}. This grid compares uniform Random
selection with the plain Greedy selector; Greedy uses 20 selector surrogates,
cosine distance, and no Jacobian term. It separates two sources of variation: a
budget slice on one fixed pair and a class-pair slice at the middle budget. All
budgets are below 0.01999. In CIFAR-100, the largest budget is 0.005 (250 of the
500 adversarial-class candidates), avoiding the degenerate regime in which
selection exhausts the candidate pool. For Tiny ImageNet we use ResNet18BN at
64\(\times\)64 rather than ConvNetBN and restrict the slice to 0.0005--0.002 for
the same candidate-pool reason.

Each cell below is an independent experiment. CIFAR-100 and Tiny ImageNet use
four pinned targets with four victim seeds per target, while SVHN uses six
pinned targets with five victim seeds per target. Target sets are shared by
Random and Greedy, by FC, GM, and SAPA, and by every budget for a given class
pair. This makes the selection methods directly paired within every attack.
Entries report ASR (\%) with clean test accuracy in parentheses; ``--'' denotes
a pending cell.
