
\section{Statistical Analysis of the Main Evaluation}
\label{app:statistical-analysis}

Table~\ref{tab:sweep_asr_clean_minus_cta} reports ASR aggregated over
$10$ attack targets and $6$ independently trained victims per target.
Because the six victim runs associated with the same target share the
target instance and poison construction, we treat the target rather than
the individual victim run as the unit of statistical analysis.

For selection method $v\in\{\mathrm{Random},\mathrm{DPP}\}$, let
$a^{(v)}_{t,s}\in\{0,1\}$ indicate whether the attack on target $t$
succeeds for victim run $s$. We first compute the attack success rate
for each target,
\begin{equation}
    r^{(v)}_t
    =
    \frac{1}{6}
    \sum_{s=1}^{6}
    a^{(v)}_{t,s},
    \qquad t=1,\ldots,10.
\end{equation}
The ASR reported in the main table is then
\begin{equation}
    \mathrm{ASR}^{(v)}
    =
    \frac{1}{10}
    \sum_{t=1}^{10}
    r^{(v)}_t.
\end{equation}
Thus, victim-training randomness is averaged within each target before
variation across attack targets is assessed. The corresponding standard
error is computed across the ten target-level success rates rather than
across the sixty individual victim outcomes.

Since Random and DPP are evaluated on the same target instances, the
comparison between selection methods is paired. For each target, we
compute
\begin{equation}
    d_t
    =
    r^{(\mathrm{DPP})}_t
    -
    r^{(\mathrm{Random})}_t,
\end{equation}
and report the mean paired improvement
\begin{equation}
    \Delta
    =
    \frac{1}{10}
    \sum_{t=1}^{10} d_t.
\end{equation}
Uncertainty in $\Delta$ is estimated by paired bootstrap resampling over
the ten targets. In each bootstrap replicate, target indices are sampled
with replacement and all victim runs associated with a sampled target
are retained for both Random and DPP. We use the resulting bootstrap
distribution to obtain a $95\%$ confidence interval for the paired
improvement. This preserves both the clustering of victim runs within a
target and the pairing between selection methods.

Tables~\ref{tab:main-stats-convnet}--\ref{tab:main-stats-vgg} report
this target-level analysis for every configuration in
Table~\ref{tab:sweep_asr_clean_minus_cta}. For compactness, clean test
accuracy is not repeated here and remains reported in the main table.
In addition to the configuration-level analysis, we summarize the
overall consistency of the selection advantage across the complete
sweep in Table~\ref{tab:aggregate-statistics}. Rather than performing
and interpreting a separate hypothesis test for every individual cell,
we report the frequency and magnitude of positive paired improvements
and an aggregate two-sided sign-flip permutation test on the paired
differences.
