# Reviewer ablation, 2026-11-06

This isolated sweep implements the four approved experiment groups. No historical
poisons/results are reused. Full-data 60-epoch selection/crafting checkpoints are
loaded from the existing `cache/surrogates/*_60ep_lr0.1_bs128_seed42` pools; partial
pools are newly trained, keyed by their exact global training-index hashes.

## Fixed protocol

CIFAR-10; poisons are dogs (class 5), targets are birds (class 2). ConvNetBN and
ResNet20BN; GM epsilon 8/255, 250 steps, step size 1/255, 8 restarts, DiffAugment
crafting; 20 selection and 5 crafting surrogates. Ordinary victims: 60 epochs,
SGD lr .1, momentum .9, no augmentation/weight decay, batch 128, decays 35/45.
The ten existing ConvNet GM target IDs are used for BOTH architectures, without
retargeting based on attack outcomes. Three paired initialization/training seeds
4200000/4200001/4200002 are used across all targets and methods. Clean-model target
predictions are recorded explicitly; raw success includes any clean free wins.

A fixed 1000-image stratified validation split of CIFAR test (100/class, excluding
all ten targets) is reserved for convergence monitoring and WO-OOD validation.
All reported clean accuracies use the remaining 9000 test images. This differs
from older tables' 10000-image CTA and must be stated in the ablation caption.

100 fixed trusted training images (10/class) are excluded from every candidate
pool and supplied only to ASD as trusted seeds. They remain in normal training.
Nested stratified visible/owned subsets use three fixed draws. In joint access
conditions the eligible dog candidates are a subset of the visible training data.
Budget always means 50/100/250 of the original 50000 images, not a percentage of
the attacker subset. Victim training always uses the entire poisoned dataset.
Each restricted-data repeat uses one subset draw and one victim seed; these are
paired repeats, not a 3x3 Cartesian product. Fraction-only rows restrict surrogate
training, but the selector still examines all eligible dog candidates.

The 120 cells are generated by `protocol.cells()`:
- 36 full-access selection cells: random, M, R, M+R, WO-pretrained, WO-OOD;
- 36 access cells at .2% for (.5,1),(.2,1),(1,.5),(1,.2),(.5,.5),(.2,.2);
- 12 joint-.2-access cells at .1%/.5%; random/M/BASIS;
- 36 defense cells: random/M/BASIS, ASD/Telltale, both models, all budgets.

M/R/BASIS use the SAME per-surrogate standardized scoring function with
`distance_margin_coef=0/1/.5`, respectively. No DPP, Jacobian, or lambda sweep.
For full-access cells one crafted set per target is replayed across three victim
seeds. Restricted-access cells craft once per target AND subset draw. All
selectors use the same final-crafting seed for a given target/draw.

## Defense adaptations and controls

ASD follows https://github.com/KuofengGao/ASD: 60/90/120 stage boundaries; ten
trusted seeds/class; add ten low-SCE-loss samples/class every five epochs;
class-agnostic lowest-loss half; finally lowest-half loss reductions after one
virtual Adam .015 epoch. SCE alpha=.1 beta=1; MixMatch temperature=.5, beta mixup
alpha=.75, lambda_u=15 ramped over120 epochs; Adam .002; 1024 steps/epoch,
64 labeled plus two views of 64 unlabeled images. BatchNorm interleaving is
retained. Crop padding4 reflect and random horizontal flip run on GPU tensors.
Official ResNet18 virtual training changes its last two stages and head. The
architecture adapter uses ConvNet's last two convolutional blocks and classifier,
and ResNet20's layer2/layer3/classifier. Other parameter gradients are disabled;
BatchNorm buffers still update as in the official virtual model.

ASD has separate clean controls and per-poisoned-dataset supervised controls:
Adam .002, 120 epochs x1024 steps, batch64, same crop/flip, all labels retained.
These are auxiliary controls in addition to the 120 primary configurations.
Assignment and CE/SCE snapshot tensors are saved without using poison identity
in the splitting/training functions. Poison masks are joined only for metrics.

Telltale follows the released artifact at https://github.com/MPaloze/Telltale,
with explicit corrections/adaptations rather than claiming bitwise reproduction:
- Its classifier is our victim architecture, trained120 epochs, SGD .1/momentum.9,
  batch128, no augmentation/WD, decays70/90. Record per-example evaluation CE.
- Truncate at the first five-validation-epoch relative range <=1% after epoch60,
  keeping at least20 subsequent epochs. Fail explicitly if no plateau exists;
  do not silently call failed convergence a failed defense.
- Use the artifact's three-layer bidirectional LSTM encoder/decoder (hidden128),
  latent dimension two-thirds of truncated length, Adam .0005, ten full-batch
  updates on6000 randomly drawn mixed samples, validation on2000 mixed samples.
- Fit normalization on ALL mixed latent vectors. The demo's separate known
  clean/poison normalizations are not used. No poison labels enter the detector.
- Follow artifact magnitude-FFT -> t-SNE(2D,perplexity30,1500 iterations,
  learning_rate200,PCA init) -> DBSCAN(eps5,min_samples5). The paper describes
  amplitude+phase/direct clustering and min_samples4, whereas the public demo
  uses magnitude/t-SNE/min_samples5; this sweep explicitly follows the demo.
- Identify the largest non-noise cluster as benign, instead of assuming arbitrary
  DBSCAN label0 is benign. No clusters triggers a diagnostic failure.
- Retrain from scratch on retained examples using the ordinary60-epoch victim
  recipe. Record pre-filter120-epoch ASR, post-filter60-epoch ASR/CTA, poison recall,
  global clean FPR and dog-class clean FPR. Clean-only controls use the same
  detection+retraining procedure and preserve clean loss traces for selected-base
  counterfactual comparisons.

## Wicked Oddities adaptations

Source https://github.com/mail-research/wicked-oddities-backdoor. Both selectors
are attached to the SAME GM crafter, not the original trigger-based attack.
WO-pretrained uses the paper's supervised-ImageNet alternative: torchvision
ResNet50 IMAGENET1K_V1, global-pooled features, bilinear224 resize, ImageNet
normalization; rank by largest mean cosine distance to50 nearest same-class
neighbors, excluding self. This is explicitly NOT the VICReg checkpoint variant.

WO-OOD uses the authors' `python/models/resnet.py` ResNet18 (vendored unchanged
except attribution),101 outputs, all dog training images and first100 sorted
TinyImageNet classes,100 epochs SGD .01/momentum.9/WD.0005, cosine schedule,
batch128. Crop padding5, rotation10 and flip are implemented on GPU. Select the
checkpoint with best accuracy on TinyImageNet validation and the reserved100 dog
validation images; rank dog examples by largest CE for the dog output100. The
released script has unreachable OOD initialization and mismatched checkpoint
paths; the explicit adapter avoids those problems. Precompute rankings once and
share across targets/budgets/victim architectures. Record all external data and
pretrained weights when reporting this baseline.

## Execution and validation

All execution (including tests) is through Slurm: 1 CPU,6G host RAM,1 full L40S.
See `sbatch/reviewer_20261106/manifest.tsv` and `submissions.tsv`. Ordinary cells
have five array tasks (two targets each); defense cells have ten (one target each).
Partial-surrogate preparation has four tasks per pool (five nets/task). Atomic
poison/result writes and per-part locks support retry without overwriting results.
ASD, OOD training and trajectory training checkpoint during long runs.

The preflight checks mathematical definitions, subset/ownership invariants,
shared scoring, checkpoint loading, actual GM perturbation bounds, both victim
architectures, ASD/MixMatch, trajectory extraction, and the complete blind detector
on synthetic data. Synthetic results are kept solely under calibration/.
